jQuery Methods Used in gpa_calculator.html:

1.  `$` (jQuery object factory / Selector Function):
    *   **Usage:** `$(document)`, `$("#id")`, `$(".class")`, `$(htmlString)`.
    *   **What it does:** The core of jQuery. It's used to select HTML elements (similar to CSS selectors), create new HTML elements, or wrap existing DOM elements to make them jQuery objects, allowing you to use jQuery methods on them. `$(document)` specifically wraps the entire HTML document.

2.  `.ready()`:
    *   **Usage:** `$(document).ready(function() { ... });`
    *   **What it does:** Ensures that the JavaScript code inside the function only runs once the DOM (Document Object Model) is fully loaded and parsed. This prevents issues where scripts try to access elements that haven't been created yet.

3.  `.click()`:
    *   **Usage:** `$("#element-id").click(function() { ... });` or `$(".element-class").click(function() { ... });`
    *   **What it does:** A shortcut method for attaching an event handler function to the "click" event of the selected elements. It's primarily used for elements that are present in the DOM when the page loads.

4.  `.text()`:
    *   **Usage:** `$(this).text()` (to get text) or `$("#result").text("New Text")` (to set text).
    *   **What it does:** Gets the combined text content of each element in the set of matched elements (including their descendants) or sets the text content of the matched elements.

5.  `.empty()`:
    *   **Usage:** `$("#container").empty();`
    *   **What it does:** Removes all child nodes (elements and text) and content from the selected elements. It effectively clears the inside of an element.

6.  `.append()`:
    *   **Usage:** `$("#container").append(htmlString);`
    *   **What it does:** Inserts the specified content to the end of each element in the set of matched elements. It's used to add new HTML dynamically.

7.  `.hide()`:
    *   **Usage:** `$("#element").hide();`
    *   **What it does:** Hides the matched elements by setting their CSS display property to 'none'.

8.  `.show()`:
    *   **Usage:** `$("#element").show();`
    *   **What it does:** Displays the matched elements. It's often used to reverse the effects of `.hide()`.

9.  `.on()`:
    *   **Usage (Event Delegation):** `$(document).on('click', '.dynamic-element-class', function() { ... });`
    *   **What it does:** Attaches one or more event handlers for the selected elements. When used with event delegation (by providing a selector as the second argument), it attaches the event handler to a parent element (e.g., `document`) and listens for events bubbling up from child elements that match the specified selector. This is crucial for handling events on elements that are added to the DOM *after* the page initially loads.

10. `.each()`:
    *   **Usage:** `$(".class").each(function() { ... });`
    *   **What it does:** Iterates over a jQuery object, executing a function for each matched element. It's useful for performing an action on every element in a collection.

11. `.data()`:
    *   **Usage:** `$(this).data('attribute-name')`
    *   **What it does:** Allows you to store arbitrary data associated with the matched elements, or retrieves the value at the named data store for the first element in the set of matched elements. In this case, it retrieves the `data-credit` attribute.

12. `.find()`:
    *   **Usage:** `$(this).find("select")`
    *   **What it does:** Gets the descendants of each element in the current set of matched elements, filtered by a selector. It's used to find specific child elements within a parent.

13. `.val()`:
    *   **Usage:** `$(this).find("select").val()`
    *   **What it does:** Gets the current value of the first element in the set of matched elements (e.g., the selected option of a `<select>` element) or sets the value of every matched element.

***

**Doubt: Can't use `.click()` instead of `.on()`?**

You *can* use `.click()` for elements that are present in the DOM when the page loads. However, `.on()` is more versatile and often preferred, especially for dynamically added content.

**Key Difference:**

*   **`.click()` (direct binding):** Attaches an event handler directly to the elements that *currently exist* in the DOM and match the selector *at the time the code runs*. If you add new elements later that match the same selector, `.click()` will *not* work for them.

*   **`.on()` (event delegation):**
    *   When used without a selector (e.g., `$("#element").on('click', function() { ... });`), it behaves similarly to `.click()` for existing elements.
    *   **When used with event delegation (e.g., `$(document).on('click', '.sem-btn', function() { ... });`):** It attaches the event handler to a *parent element* (in our case, `document`, which is always present). It then listens for click events that *bubble up* from its descendants. If a click event originates from a descendant that matches the provided selector (`.sem-btn`), then the handler function is executed.
    *   **Benefit for your GPA Calculator:** The semester buttons (`.sem-btn`) are added dynamically *after* a branch button is clicked. If you used `$(".sem-btn").click(...)`, it would only bind to `.sem-btn` elements that existed *when that line of code first ran* (which is none at that point). By using `$(document).on('click', '.sem-btn', ...)`, the event listener is on the `document` itself, and it effectively "watches" for any `.sem-btn` that appears later and is clicked. This ensures your dynamically created semester buttons are interactive.

**In summary:**

*   Use `.click()` for elements that are *always* present when the page loads.
*   Use `.on()` (with event delegation) for elements that are added to the page *dynamically* or might not exist when the page initially loads. It's generally a safer and more flexible approach for dynamic content.
